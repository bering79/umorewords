# Не только речь — MVP главной страницы

Это самостоятельный прототип без сборщика: `index.html` + `styles.css` + `app.js`.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере.

Для разработки можно открыть папку в VS Code и использовать Live Server.

## Что уже реализовано

- desktop + mobile-first адаптация;
- sticky header и мобильное меню;
- hero-блок;
- сценарий «Мне сейчас тяжело» с выбором нескольких ситуаций;
- рекомендация первого маршрута;
- раздел «Разобраться»;
- раздел «Попробовать»;
- истории;
- блок поддержки;
- раздел для родителей;
- «О проекте»;
- footer;
- интерактив «Что я хочу сказать?» с 4 шагами;
- сохранение маленького шага и результата интерактива в localStorage;
- keyboard Escape для закрытия интерактива;
- reduced-motion;
- базовая доступность.

## Что пока является заглушкой

Ссылки на статьи, истории, страницу родителей и другие разделы ведут на якоря-заглушки. Это намеренно: следующими шагами эти страницы можно реализовать на той же компонентной системе.

## Следующий технический этап

Перенести прототип в React/Next.js или другой выбранный стек, вынести контент в отдельные данные (`content/`) и заменить заглушки реальными страницами.
