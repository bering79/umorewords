# Не только речь — MVP v2

## Реализовано
- `index.html` — главная страница из первого MVP.
- `difficult.html` — полноценный раздел «Мне сейчас тяжело».
- `presentation.html` — отдельный маршрут «Мне предстоит выступление».
- Общая дизайн-система: `styles.css`.
- Состояния, выбор ситуаций, переходы и интерактив: JS-файлы страниц.
- Mobile-first адаптация.
- Клавиатурная доступность базовых элементов и `prefers-reduced-motion` из общей CSS.
- Сохранение результата маршрута выступления в `localStorage`.

## UX-модель
`Мне сейчас тяжело` → выбор ситуации → рекомендация первого шага → маршрут.

Для ситуации «Мне предстоит выступление»:
`ситуация → тема → главная мысль → точка опоры → что важно сказать → итог`.

## Важное содержательное ограничение
Маршрут не обещает контроля над заиканием и не использует «просто успокойся», «говори медленнее» или «никто не заметит». Цель — подготовить содержание и опоры для коммуникации, а не сделать речь «идеальной».

## Запуск
Распаковать ZIP и открыть `index.html`.
